## 💻 How to Run Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18 or higher) installed on your system.

### 1. Clone the repository
```bash
git clone https://github.com/adityakumar23-code/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the local development server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port indicated in your terminal) to view the website.

## 🌐 Deploy to Vercel (Free & Instant)

### Option A: Via Vercel Web Dashboard (Recommended)
1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of Aditya Kumar portfolio"
   git branch -M main
   git remote add origin https://github.com/adityakumar23-code/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
3. Click **"Add New..."** > **"Project"**.
4. Import your `portfolio` repository.
5. Vercel will automatically detect **Vite**:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
6. Click **"Deploy"**. Your portfolio will be live with a free `.vercel.app` URL and automatic updates on every push!

### Option B: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
Follow the terminal prompts and accept the default settings.
